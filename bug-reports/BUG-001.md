# BUG-001 — Typing in Last Name overwrites First Name

**App:** Swag Labs  
**Account where it failed:** [Enter the username you used]

## Steps

1. Add the Sauce Labs Backpack to the cart.
2. Open the cart and click Checkout.
3. Enter `Alex` in First Name.
4. Click Last Name and type `Tester`.

## Expected result

First Name stays `Alex` and Last Name shows `Tester`.

## Actual result

Last Name stays blank. Each letter typed replaces the contents of First Name,
leaving only the letter.

## Comparison

The same steps worked as expected with `standard_user`.
